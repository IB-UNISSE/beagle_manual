Comandos básicos de Linux

Esta sección reúne comandos esenciales para trabajar en BEAGLE desde la terminal. No pretende ser un curso completo de Linux, sino una guía práctica para moverse entre carpetas, revisar archivos, consultar el uso de disco, monitorear procesos y trabajar de forma más segura dentro del servidor.

Estos comandos son útiles después de ingresar por SSH y antes de comenzar a trabajar con ambientes, contenedores de Apptainer o trabajos enviados mediante Slurm.

WarningImportante

Evita ejecutar análisis largos directamente en la terminal de acceso si el servidor utiliza Slurm para administrar trabajos. Para análisis pesados, usa scripts de trabajo y envíalos mediante sbatch.

La terminal debe usarse principalmente para preparar archivos, revisar resultados, organizar carpetas y monitorear tus procesos.

Comandos esenciales para moverte

¿Dónde estoy?

Para saber en qué carpeta te encuentras actualmente, usa:

pwd

El comando pwd significa print working directory y muestra la ruta completa de tu ubicación actual.

Listar archivos y carpetas

Para listar el contenido de la carpeta actual:

ls

Para ver más detalles, como permisos, tamaño y fecha de modificación:

ls -lh

Para mostrar también archivos ocultos:

ls -lah
TipArchivos ocultos

En Linux, los archivos o carpetas que comienzan con punto (.) son ocultos. Por ejemplo: .bashrc, .ssh/ o .config/.

Cambiar de carpeta

Para entrar a una carpeta específica:

cd /ruta/a/la/carpeta

Para ir a tu carpeta personal:

cd ~

Para subir un nivel en la estructura de carpetas:

cd ..

Para regresar a la carpeta anterior:

cd -
TipAutocompletado

Puedes usar la tecla Tab para autocompletar nombres de archivos y carpetas. Esto reduce errores al escribir rutas largas.

Crear, copiar, mover y borrar archivos

Crear carpetas

Para crear una carpeta:

mkdir proyecto

Para crear varias carpetas dentro de un proyecto:

mkdir -p proyecto/{data,scripts,results,logs,metadata}

Este comando crea una estructura básica útil para organizar análisis bioinformáticos:

proyecto/
├── data/
├── scripts/
├── results/
├── logs/
└── metadata/

Copiar archivos y carpetas

Para copiar un archivo:

cp archivoA archivoB

Para copiar una carpeta completa:

cp -r carpetaA carpetaB

Mover o renombrar archivos

Para renombrar un archivo:

mv viejo.txt nuevo.txt

Para mover una carpeta a otra ruta:

mv carpeta /otra/ruta/

Borrar archivos y carpetas

Para borrar un archivo:

rm archivo.txt

Para borrar una carpeta completa:

rm -r carpeta/

Cuidado con rm

El comando rm borra archivos directamente. En la terminal no hay papelera de reciclaje.

Antes de borrar, revisa con:

ls

También puedes revisar el contenido de una carpeta antes de eliminarla:

ls carpeta/

Revisar archivos rápidamente

Ver el contenido completo de un archivo

cat archivo.txt

Este comando es útil para archivos pequeños. Para archivos grandes, es mejor usar less, head o tail.

Ver las primeras líneas

head archivo.txt

Para mostrar un número específico de líneas:

head -n 20 archivo.txt

Ver las últimas líneas

tail archivo.txt

Para mostrar un número específico de líneas:

tail -n 20 archivo.txt

Seguir un archivo en tiempo real

Esto es útil para revisar archivos de salida o archivos .log mientras se está ejecutando un proceso:

tail -f archivo.log

Para salir, presiona:

Ctrl + c

Ver archivos largos página por página

less archivo.txt

Dentro de less, puedes moverte con las flechas del teclado o con la barra espaciadora.

Para salir de less, presiona:

q

Revisar almacenamiento y tamaño de datos

Espacio libre por partición

Para revisar el espacio disponible en los discos o particiones montadas:

df -h

La opción -h muestra los tamaños en formato legible, por ejemplo en G o T.

Tamaño de una carpeta

Para revisar el tamaño total de una carpeta:

du -sh carpeta/

Para revisar el tamaño de todo lo que hay en la carpeta actual:

du -sh *

Encontrar lo que más pesa

du -sh * | sort -h

Este comando calcula el tamaño de los archivos y carpetas, y luego los ordena por tamaño.

TipBuen hábito

Revisa tu uso de disco antes de lanzar análisis grandes, especialmente si trabajarás con archivos FASTQ, BAM, VCF, ensamblajes o resultados intermedios grandes.

Revisar recursos disponibles: CPU y RAM

Revisar CPU

Para ver información del procesador, número de núcleos e hilos disponibles:

lscpu

Revisar memoria RAM

Para revisar la memoria disponible:

free -h

Ver procesos en tiempo real

top

Para salir de top, presiona:

q

Si está instalado, htop suele ser más cómodo:

htop
NoteNota

En servidores administrados con Slurm, la disponibilidad real de CPU y memoria para tus análisis depende de los recursos solicitados en el script de trabajo, no solo de lo que aparece con lscpu o free -h.

Monitoreo básico de procesos

Un proceso es un programa que se está ejecutando. Cada proceso tiene un identificador llamado PID (Process ID).

Ver procesos de tu usuario

ps -u $USER

Una versión más legible y ordenada por uso de CPU:

ps -u $USER -o pid,ppid,cmd,%cpu,%mem,etime --sort=-%cpu | head -n 20

Buscar un proceso por nombre

pgrep -a nombre_programa

Por ejemplo:

pgrep -a mafft

Ver el PID de un proceso específico

pidof nombre_programa

Detener procesos

WarningAntes de detener un proceso

Asegúrate de que el proceso sea tuyo y de que realmente quieras detenerlo. No intentes detener procesos de otros usuarios o procesos del sistema.

Detener un proceso por PID

Primero intenta un apagado limpio:

kill PID

Por ejemplo:

kill 12345

Si el proceso no se detiene, puedes forzarlo:

kill -9 PID
Warningkill -9 como último recurso

Usa kill normal primero. El comando kill -9 fuerza el cierre inmediato del proceso y puede dejar archivos incompletos o resultados corruptos.

Detener varios procesos por nombre

Primero verifica qué procesos coinciden con el nombre:

pgrep -a nombre_programa

Después puedes detenerlos con:

pkill nombre_programa

Por ejemplo:

pgrep -a mafft
pkill mafft

Sesiones persistentes con tmux

Cuando trabajas por SSH, la conexión puede cortarse por fallas de red, suspensión de la computadora o cierre accidental de la terminal. Para evitar perder tu trabajo, es recomendable usar sesiones persistentes con tmux.

Crear una sesión

tmux new -s mi_sesion

Salir de la sesión sin cerrarla

Presiona:

Ctrl + b

Luego suelta las teclas y presiona:

d

Esto te desconecta de la sesión, pero la sesión sigue activa en el servidor.

Volver a entrar a una sesión

tmux attach -t mi_sesion

Listar sesiones activas

tmux ls
TipRecomendación

Usa tmux cuando estés revisando archivos, preparando datos o ejecutando tareas cortas. Para análisis largos o pesados, usa Slurm.

Permisos y propiedad

Ver permisos

ls -l

La salida muestra permisos, propietario, grupo, tamaño, fecha y nombre del archivo.

Ejemplo:

-rw-r--r-- 1 usuario grupo 1200 Jun  8  archivo.txt

Los permisos se interpretan de la siguiente forma:

rw- r-- r--
│   │   │
│   │   └── otros usuarios
│   └────── grupo
└────────── dueño

Donde:

  • r significa lectura.
  • w significa escritura.
  • x significa ejecución.

Dar permiso de ejecución a un script

chmod +x script.sh

Esto permite ejecutar el script así:

./script.sh

Permisos comunes

Para archivos de texto o datos:

chmod 644 archivo.txt

Para carpetas o scripts ejecutables:

chmod 755 carpeta/

De forma general:

  • 644: lectura para todos, escritura solo para el dueño.
  • 755: el dueño puede escribir; otros pueden leer y entrar.

Edición rápida de archivos con nano

nano es un editor de texto sencillo que funciona dentro de la terminal.

Para abrir o crear un archivo:

nano archivo.txt

Atajos útiles:

Acción Atajo
Guardar Ctrl + O, luego Enter
Salir Ctrl + X
Buscar texto Ctrl + W
Cortar línea Ctrl + K
Pegar línea Ctrl + U
NoteNota

También existen otros editores como vim o emacs, pero nano suele ser más sencillo para comenzar.

Compresión y empaquetado

Crear un archivo .tar.gz

Para comprimir una carpeta completa:

tar -czvf proyecto.tar.gz proyecto/

Donde:

  • c crea un archivo.
  • z comprime con gzip.
  • v muestra el progreso.
  • f indica el nombre del archivo de salida.

Extraer un archivo .tar.gz

tar -xzvf proyecto.tar.gz

Comprimir un archivo con gzip

gzip archivo.txt

Esto genera:

archivo.txt.gz

Descomprimir un archivo .gz

gunzip archivo.txt.gz

Compresión paralela con pigz

pigz funciona de forma similar a gzip, pero puede usar varios núcleos para comprimir más rápido.

Comprimir con pigz

pigz archivo_grande.fastq

Esto genera:

archivo_grande.fastq.gz

Descomprimir con unpigz

unpigz archivo_grande.fastq.gz
TipArchivos FASTQ

En bioinformática es común trabajar con archivos .fastq.gz o .fq.gz. Generalmente no es necesario descomprimirlos para todos los programas, ya que muchas herramientas pueden leerlos comprimidos.

Revisar comandos usados previamente

La terminal guarda un historial de comandos. Para verlo:

history

También puedes usar las flechas del teclado para recuperar comandos anteriores.

Para buscar comandos usados anteriormente, presiona:

Ctrl + r

y escribe una parte del comando que quieres encontrar.

Buenas prácticas generales

  • Revisa siempre en qué carpeta estás con pwd antes de mover, copiar o borrar archivos.
  • Usa ls antes de ejecutar comandos destructivos como rm.
  • Organiza tus proyectos en carpetas como data/, scripts/, results/, logs/ y metadata/.
  • Guarda los comandos importantes en scripts dentro de la carpeta scripts/.
  • Usa nombres de archivos claros, sin espacios y con fechas o identificadores cuando sea necesario.
  • Revisa el espacio disponible con df -h y el tamaño de tus carpetas con du -sh.
  • Para análisis largos o pesados, usa Slurm en lugar de ejecutar directamente en la terminal.
